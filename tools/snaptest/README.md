# בדיקת מטמון הכרטיסים (שרת 166)

מריצה את `apps-script.gs` עצמו ב-node (`vm`), מול גיליון, מטמון ומאפיינים מדומים
בזיכרון (`mock.js`). אין רשת, אין גוגל, אין נתונים אמיתיים — שמות וטלפונים מומצאים.

```
node tools/snaptest/eq.js        # סדרה אקראית: כל קריאה מול חישוב מלא. SEED=2 N=500 לשנות
node tools/snaptest/flight.js    # חישוב אחד בכל פעם · מי שלא השתנה · שמירה בלי חישוב · לוח
node tools/snaptest/board.js     # לוח הישיבה אחרי לימוד של תלמיד שבו
node tools/snaptest/hsnap.js     # התמונה השמורה לבית: רישום/ביטול הגרלה, הגנת ההפעלה, קריאות חוזרות
GS=<קובץ ישן> node tools/snaptest/load.js   # עומס ערב: כמה חישובים מלאים (להשוואה בין גרסאות)
```

`eq.js` יוצא בקוד 1 אם נמצא הבדל. הצלחה כאן היא נכונות מול החישוב המלא בהדמיה —
**לא** הוכחה לזמנים בטלפונים בפועל. הזמנים בשטח — `?tm=1` ו-`.github/workflows/probe.yml`.
פונקציה של Apps Script שלא מודמתה מוחזרת כ"לא עושה כלום", ומודפסת בסוף (`missing`).
